# Python Exercises for Students

This folder contains exercises organized by lesson topic.

## Structure

| File | Topic | Difficulty |
|------|-------|------------|
| `lesson1_comments.py` | Comments | Beginner |
| `lesson2_variables.py` | Variables & Data Types | Beginner |
| `lesson3_operations.py` | Operations & Type Checking | Beginner |
| `solutions/` | Answer keys for all exercises | — |

## How to Use

1. Each exercise file contains **tasks** marked with `# Task X.X — description`
2. Write your code directly below each task
3. Run the file to check your output
4. Compare with the solution in `solutions/` folder

## Rules

- Try each task before looking at the solution
- If stuck for more than 10 minutes, check the hint (if provided)
- Experiment — change values and see what happens!
